# BEELINE-2026 PROJECT COMPLETE EXPLORATION

## PROJECT OVERVIEW

Volunteer+ is a dual-mode platform with:
- Backend: FastAPI + Telegram Bot
- Frontend: React + Vite + Tailwind CSS
- Database: SQLite
- Users: Coordinators, Volunteers, Public

## AUTHENTICATION FLOW

### Coordinator Login
- Endpoint: POST /api/auth/login
- Credential: Password only
- Response: JWT token with role="coordinator"

### Volunteer Registration
- Endpoint: POST /api/auth/register
- Fields: full_name, city, email, password
- Response: JWT token with role="volunteer"

### Volunteer Login
- Endpoint: POST /api/auth/login/volunteer
- Credentials: email + password
- Password: PBKDF2-SHA256 (100k iterations)

### JWT Token Details
- Algorithm: HS256
- Expiration: 24 hours
- Stored in: localStorage as 'volunteer_plus_token'
