# Отчёт: веб-дашборд Volunteer+ (React)

Документ для подготовки презентации по фронтенду в каталоге `frontend/`.

---

## 1. Назначение продукта

Одностраничное веб-приложение для **координаторов** и **волонтёров**: обзор метрик, календарь мероприятий, рейтинги, команда, модерация событий с ИИ-подсказкой, личный кабинет волонтёра с загрузкой подтверждений. Интерфейс на **русском**, ориентирован на быстрый обзор «за минуту».

---

## 2. Технологический стек

| Слой | Технология |
|------|------------|
| UI | React 18, функциональные компоненты, хуки |
| Маршрутизация | `react-router-dom` v6 |
| Стили | Tailwind CSS 3, кастомная палитра (`primary` / `accent` / `bee`) |
| Иконки | `lucide-react` |
| Графики | `recharts` (Area, Pie, Bar) |
| Сборка | Vite 6, `@vitejs/plugin-react` |
| API | нативный `fetch`, единый модуль `api.js` |

**Связь с бэкендом:** в dev прокси `/api` → `http://localhost:8000` (`vite.config.js`). В проде предполагается раздача SPA с того же хоста, что и API (относительные пути).

**Дополнительно:** в `index.html` подключены **Google Fonts (Inter)** и **Telegram Web App** (`telegram-web-app.js`); в `main.jsx` вызываются `WebApp.ready()` и `expand()` — задел под мини-приложение в Telegram.

## 3. Архитектура приложения

### Точки входа

- `main.jsx` — `BrowserRouter`, монтирование `App`, глобальные стили `index.css`.
- `App.jsx` — все маршруты и **три режима оболочки**:
  - **PublicLayout** — верхняя навигация `PublicNavbar`, контент в `max-w-6xl`.
  - **SidebarLayout** — фиксированный сайдбар слева + основная область (классы из `App.css`).
  - **Защита маршрутов:**
    - `AuthRoute` — есть JWT в `localStorage`, иначе редирект на `/login`.
    - `CoordinatorRoute` — токен + `user.role === 'coordinator'`.
    - `SmartRoute` — без токена публичный вид с навбаром, с токеном — дашборд с сайдбаром.

### Маршруты

| Путь | Доступ | Суть экрана |
|------|--------|-------------|
| `/login`, `/register` | Все | Email/пароль, сохранение токена и пользователя |
| `/` | SmartRoute | Обзор (KPI, графики, лента, топ) |
| `/calendar` | SmartRoute | Календарь/список по месяцам, создание события |
| `/ratings` | SmartRoute | Подиум, таблица, достижения |
| `/volunteer/:id` | SmartRoute | Публичная карточка волонтёра |
| `/team`, `/team/:id` | Только координатор | Реестр и деталь из панели координатора |
| `/moderation` | Координатор | Очередь и история модерации + ИИ |
| `/my-events`, `/settings` | Любой залогиненный | Мои события и настройки |

**Замечание:** в `PublicNavbar.jsx` для координатора ссылка ведёт на **`/admin`**, такого маршрута в `App.jsx` нет — при клике возможен редирект на главную. Имеет смысл заменить на `/` или `/team`.

## 4. Слой данных (`api.js`)

- **Хранение сессии:** `localStorage` — ключи `volunteer_plus_token`, `volunteer_plus_user` (роль, id, имя).
- **Заголовки:** `Authorization: Bearer …` для защищённых запросов.
- **401:** очистка токена и переход на `/login`.
- **Группы методов API:**
  - Аутентификация: `login`, `register`, `getMe`
  - Публичные: события, статистика, лидерборд, достижения, активность, графики
  - Координатор/авторизованные: список волонтёров, создание/обновление событий, статус волонтёра
  - Волонтёр: «мои события», верификация (`FormData` + фото), заявки, отзывы
  - Модерация: очередь, история, решение по событию

## 5. Страницы — содержание экранов

### Обзор (`Dashboard.jsx`)

- Четыре **StatsCard**: волонтёры (всего/активные), мероприятия, активность за неделю/месяц, % завершения.
- **Recharts AreaChart** — мероприятия за 14 дней; при ошибке API — локальный fallback из списка событий.
- **PieChart** — распределение planned / completed / cancelled.
- Блоки: последние 5 событий (`EventCard`), **ActivityFeed** (`/api/activity`), компактный **Leaderboard** топ-5 со ссылкой на полный рейтинг.

**Тезис для презентации:** один экран — полная картина для координатора.

### Календарь (`Calendar.jsx`)

- Сводные карточки: всего / запланировано / завершено.
- Вкладки: все / предстоящие / завершённые.
- Группировка по месяцу, сортировка по дате.
- Модальное окно **создания события** (название, место, `datetime-local`).

### Рейтинг (`Ratings.jsx`)

- Вкладки: **лидерборд** и **достижения**.
- Подиум топ-3 (клик → `/volunteer/:id`), fallback если участников меньше трёх.
- Столбчатая диаграмма топ-10 по баллам.
- Таблица: место, имя, город, прогресс-бар относительно лидера, баллы, число отчётов.
- Достижения: сетка карточек с градиентами по `badge_type` (gold/silver/bronze).

### Команда (`Team.jsx`) — координатор

- Поиск по имени/городу, фильтры: все / активные / неактивные.
- Сетка карточек: аватар-буква, город, баллы, переключение статуса, переход в `/team/:id`.

### Карточка волонтёра (`VolunteerDetail.jsx`)

- Профиль, статус, город, Telegram, дата регистрации.
- Метрики: баллы, отчёты, достижения, место в рейтинге.
- Блок **«Рейтинг организатора»** (если есть данные): средняя оценка, отзывы, участники, число мероприятий.
- Списки отчётов со статусами, достижения, отзывы с звёздами.

### Модерация (`ModerationPage.jsx`) — координатор

- Очередь: карточка события, волонтёр, место, дата.
- Блок **ИИ-анализ**: процент `ai_score`, список `ai_reasons`, координаты.
- Действия: одобрить / отклонить; вкладка **история** в виде таблицы.

**Тезис:** человек + ИИ в одном процессе модерации.

### Мои мероприятия (`MyEvents.jsx`) — волонтёр

- Список событий пользователя со статусами.
- Создание события в модалке (с описанием).
- Для ожидающих верификации: загрузка фото, опционально геолокация браузера, отправка на `/api/events/:id/verify` с отображением результата ИИ.

### Настройки (`SettingsPage.jsx`)

- Информация о системе (версия, БД, бот, среда).
- Профиль из `localStorage`: роль координатор/волонтёр.
- Ссылки: Swagger, Telegram-бот.

### Вход / регистрация (`Login.jsx`, `Register.jsx`)

- Единый визуальный стиль: тёмный фон, акцентная полоса, белая карточка.
- Регистрация: ФИО, город, email, пароль + подтверждение.

## 6. Переиспользуемые компоненты

- **Sidebar** — разное меню для координатора (включая «Модерация») и волонтёра («Мои мероприятия»), выход.
- **PublicNavbar** — лого, обзор/календарь/рейтинг, вход/регистрация или кабинет.
- **StatsCard** — единый KPI-блок с цветовыми схемами иконок.
- **EventCard** — статус, дата/место, заявки, рейтинг, участники; для залогиненных: заявка на planned, отзыв на completed.
- **Leaderboard** — топ-3 с подиум-стилями; в полном режиме — остальные места с прогресс-баром.
- **ActivityFeed** — типы событий (volunteer, submission, achievement, event), относительное время по-русски.

## 8. Адаптивность и ограничения

- На ширине ≤768px у основного контента `margin-left: 0`, но сайдбар остаётся фиксированным — отдельного мобильного меню (гамбургер) в коде нет; для презентации: десктоп-first, мобильная навигация — зона улучшения.

---

## 9. Сценарий демо (3–5 минут)

1. Открыть сайт **без входа** — публичный навбар, обзор, календарь, рейтинг.
2. **Войти координатором** — сайдбар, «Команда», «Модерация», создать событие в календаре.
3. **Войти волонтёром** — «Мои мероприятия», создать событие, загрузить фото верификации (при работающем бэкенде).
4. Показать **рейтинг**: подиум + график + таблица.
5. Упомянуть **Telegram WebApp** в `index.html` / `main.jsx` как сценарий открытия из бота.
